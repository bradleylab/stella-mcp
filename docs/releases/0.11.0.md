# Stella MCP 0.11.0

This behavior-preserving maintenance release separates the package's major
responsibilities into focused modules while retaining the public interfaces and
model behavior introduced through 0.10.0.

## Highlights

- Organize MCP tool schemas and handlers into build, I/O, inspection, module,
  and simulation domains behind the existing compatibility facades.
- Separate model records and lifecycle operations from layout calculations
  while preserving `stella_mcp.xmile` imports and `StellaModel` delegates.
- Separate XMILE parsing and export while preserving compatibility warnings,
  unknown supported XML content, and generated output.
- Encapsulate session model registries and current-model state in a tested
  `SessionStore` with explicit cleanup behavior.
- Document dependency boundaries, module ownership, extension points, session
  lifecycle assumptions, compatibility guarantees, and release gates.

The core install continues to require only MCP. Simulation, scenario analysis,
sensitivity analysis, and calibration remain available through the optional
`sim` extra:

```bash
pip install "stella-mcp[sim]==0.11.0"
```
