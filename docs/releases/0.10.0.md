# Stella MCP 0.10.0

This release adds parameter calibration to the PySD-backed simulation stack.

## Highlights

- Fit constant auxiliary and flow parameters from inline or CSV observations
  with local least-squares or seeded differential evolution.
- Report a weighted sum-of-squares objective separately from native-unit SSE
  and RMSE for every observed target.
- Return effective optimizer settings, convergence state, backend status, and
  termination details.
- Reject unsupported stock and non-constant parameter fits, invalid optimizer
  controls, out-of-window observations, and non-finite final simulations.
- Exercise the complete optional simulation, analysis, and calibration stack
  in CI and validate package metadata before publication.

Install the optional simulation dependencies with:

```bash
pip install "stella-mcp[sim]==0.10.0"
```
