# Stella and PySD Numeric Comparison

## Result

Stella Professional 4.1.1 and PySD 3.14.3 produced identical values for the
accumulator model at all five saved time points from 0 through 4 years. The
maximum absolute and relative errors were both 0 for `Accumulator`, `input`,
and `rate`.

This is raw comparison evidence, not a selected tolerance. Time grids must
match exactly, no interpolation is performed, and the comparator has no pass
threshold.

## Stella Export

The model was opened and run to time 4 in Stella Professional 4.1.1. In
**Model > Export Data**, the active export link selected all model variables,
vertical orientation, every DT, and numeric values. **Export All** produced the
non-empty CSV committed as
`results/evaluation/0.12.0-accumulator-stella.csv`.

The exported model had the same strict-parsed structure as
`tests/fixtures/compat_corpus/stella_4_1_1_accumulator.stmx`; its only byte-level
difference was one trailing blank line. The committed fixture is therefore the
reproduction input. Its Stella provenance and desktop acceptance checks are
recorded in `tests/fixtures/compat_corpus/manifest.json`.

## Reproduction

From a source checkout with the simulation dependencies installed:

```bash
uv run --extra sim python -m evaluation.desktop_parity \
  tests/fixtures/compat_corpus/stella_4_1_1_accumulator.stmx \
  results/evaluation/0.12.0-accumulator-stella.csv \
  --pysd-output results/evaluation/0.12.0-accumulator-pysd.csv \
  --output-json results/evaluation/0.12.0-accumulator-parity.json \
  --stella-version 4.1.1 \
  --stella-time Years \
  --column Accumulator=Accumulator \
  --column input=input \
  --column rate=rate
```

The JSON report records both engine versions, the model and CSV SHA-256 hashes,
the simulation settings and warnings, and the complete comparator result. The
PySD CSV is regenerated by this command; the Stella CSV is retained as the raw
desktop-application output.

## Scope

The model is a one-stock linear Euler accumulator with a unit time step. This
result closes the missing numeric-export check for that compatibility fixture;
it does not establish parity for nonlinear equations, lookup functions,
alternative integration methods, or larger models.
