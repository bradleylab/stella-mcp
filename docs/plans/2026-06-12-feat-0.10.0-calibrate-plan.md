# Stella MCP 0.10.0 — Parameter Calibration

> **Status: IMPLEMENTED / HARDENING.** Tasks 1-3 are implemented; release hardening is governed by `docs/plans/2026-07-09-hardening-maintainability-spec.md`. This file remains the historical design record. The four analytical forks were settled with defaults locked 2026-06-12, then independently reviewed twice; the findings were folded into the implementation.

**Goal:** Close the simulation arc (what-if → sensitivity → **calibrate**). Add the inverse of `simulate`: given an observed time-series, find the parameter values that make the model reproduce it. `simulate` maps *parameters → output*; `calibrate` maps *observed output → parameters*.

**Architecture:** Another composition of the existing engine. `calibrate` opens `_compile_runner` **once** and runs an optimizer whose every objective evaluation is a single `runner.run(params={...})` — exactly the access pattern the 0.9.0 statelessness verification cleared (PySD is stateless across repeated `run(params=)` calls, so the optimizer can call `.run()` hundreds of times on one compiled model). New code lives in a focused `stella_mcp/calibrate.py`. `simulate.py` gains **one shared helper** (`constant_parameter_value`, extracted so both `analysis.py` and `calibrate.py` classify a variable's defining constant the same way); `analysis.py` is otherwise untouched.

**Dependency posture:** `numpy`, `pandas`, `scipy`, and `pysd` are declared directly in the `sim` extra because project modules import each distribution directly. Simulation-stack imports remain inside functions, so the server still imports with core dependencies only.

**Prerequisite:** 0.9.0 shipped (`_compile_runner`, `resolve_overrides`/`summarize_run`/`method_warnings`, the `sim` extra, the `_READ_ONLY/_IDEMPOTENT/_MUTATING/_DESTRUCTIVE` annotation sets + partition test, lockfile CI).

## Locked decisions (the four analytical forks — coding cardinal #3)

1. **Optimizer:** support **both**, default `least_squares` (local, fast, needs a starting guess, yields approximate parameter uncertainty from the Jacobian). `differential_evolution` (global, stochastic, **requires finite bounds**) is the escape hatch for multimodal fits with no good guess. `method` is an enum `["least_squares", "differential_evolution"]`.
2. **Objective:** `sse` residual vector with **optional per-target weights**, default **unweighted**. `least_squares` consumes the raw residual vector natively; `differential_evolution` squares-and-sums it to a scalar. Weights are the knob for multi-scale targets (e.g. `Atmosphere ~400` vs `Ocean ~38000`) — exposed, off by default, **with a warning** when targets span >1 order of magnitude and no weights are given (review fix M1).
3. **Bounds & parameter eligibility:** optional bounds for `least_squares` (uses `trf`, which handles bounded and unbounded), **required** for `differential_evolution`. Each parameter's `initial` defaults to the **model's current constant value** (read from the model, never invented). Validate `min < max` and `initial ∈ [min, max]`. **Only numeric-constant auxes/flows are calibratable** — stocks and non-constant equations are **rejected** (review BLOCKER; see below).
4. **Data↔time alignment:** simulate on the model's **native** `[initial_time, final_time]` window and **linear-interpolate the sim onto the observation times** (`numpy.interp`). **Reject obs times outside the window with an explicit pre-check** (no extrapolation — cardinal: don't invent values; `numpy.interp` silently *clamps*, so the guard cannot rely on it). Changing `final_time` to fit the data would be a methodological change, so it is *not* automatic; a `time_window` override is **reserved** (out of scope for 0.10.0).

**Honesty caveat (documented in output + README):** the `std_error` from `least_squares` is the linearized covariance `σ²·(JᵀJ)⁻¹` with `σ² = SSE/(m−n)`, `SSE = Σ residual² = 2·result.cost`. It assumes local linearity at the optimum and iid Gaussian residuals — a useful first-order "± on the fitted value," **not** a posterior. It is returned **only** when `m > n`, `JᵀJ` is full-rank/well-conditioned, and **no fitted parameter sits at a bound** (an active bound removes a degree of freedom and inflates the others); otherwise `std_error = None` + a warning. Under non-default `weights` the covariance is interpretable as a standard error **only if** the weights are inverse-σ scale — documented as a caveat. `differential_evolution` returns no Jacobian, so `std_error` is `null` there.

## Review findings folded in (2026-06-14)

Two independent reviews (codex; adversarial reviewer that executed the real `pysd 3.14.3` / `scipy 1.17.1` stack). They **converged** on one blocker and the same top issues. Each is mapped to where it is now handled.

- **BLOCKER — stocks are not calibratable.** Both reviewers; **empirically confirmed**: `runner.run(params={"Stock": 50})` returns `[50, 50, 50, …]` — PySD *pins the stock to a constant for the whole run*, it does **not** set the stock's initial value. Listing a stock as a fit parameter would silently flatten a dynamic model. → **Fix:** parameter-eligibility gate rejects stocks and non-constant equations (Task 2 Step 1; decision #3). Fitting stock initials is explicitly unsupported in 0.10.0 (Scope guard + README).
- **HIGH — PySD name contract.** `run_simulation` maps user names → PySD **display names** before `runner.run(params=)`. A naive `dict(zip(names, x))` would misaddress normalized/underscore names. → **Fix:** precompute the display-name map once and key trial params by display name (Task 1 Step 4; Task 2 Step 1).
- **HIGH — flat penalty causes false convergence.** Both reviewers; **reproduced**: starting `least_squares` inside a constant-penalty region returns after **1 eval** with `status=1` ("converged") and `x` unchanged. → **Fix:** require finite residuals at `x0` (raise if infeasible); make the penalty **distance-aware** so its Jacobian points back toward feasibility; gate `converged` on `result.status > 0` and flag "terminated at the initial guess" as non-convergence (Task 1 Step 4; Task 2 Steps 2 & 4).
- **MEDIUM (M1) — unweighted SSE across multi-scale targets** silently lets the large-magnitude target dominate. → warn when targets span >1 order of magnitude and no weights given (decision #2; Task 2 Step 4).
- **MEDIUM — covariance guards** (`SSE = 2·result.cost`; require `m>n`, full rank, good conditioning, no active bounds; optionally report `cond(JᵀJ)`) and **weighted-`std_error` caveat** (Honesty caveat; Task 2 Step 3).
- **MEDIUM — `max_nfev` ↛ DE.** Passing it as `maxiter` blows the eval budget (`maxiter·popsize·n`). → expose DE `maxiter`/`popsize` (or derive from a true budget) and report `result.nfev` (Task 2 Step 2).
- **MEDIUM — lazy imports must include `numpy`** (not just scipy/pandas): `tool_handlers.py` imports tool modules at load, so any top-level sim-stack import in `calibrate.py` breaks the server without the `sim` extra (Task 1 Step 4; Task 4 regression check).
- **MEDIUM — time-alignment edge cases:** single **shared** obs grid across all targets (per-target grids reserved); emit model **time units**; warn when `min(diff(obs_time)) < model dt/SAVEPER` (interpolation looks finer than the sim) (Task 1 Step 3).
- **LOW — `numpy.interp` clamps** rather than raising → the out-of-window check is a standalone pre-check with a `dt`-scaled boundary tolerance; test exact-boundary and just-past-boundary (Task 1 Step 3/5).
- **LOW — scipy `seed=` → `rng=`** deprecation path → use `rng` where the installed scipy supports it, fall back to `seed=` (Task 2 Step 2).
- **LOW — carry `method_warnings(model)`** (Euler-backend note) into calibrate output (Task 2 Step 4).
- **LOW — `idempotentHint`** defensible only while DE is seeded → reject `seed=None`; add a code comment at the annotation site (Task 3 Step 2).

Both verdicts: **sound with the noted fixes; do not build until the stock/parameter-semantics blocker is resolved** — which this revision does, in the design.

## Scope guard

- **Frequentist point-estimate fitting only.** No Bayesian/MCMC calibration (the Stan/JAX idea is a separate, larger arc).
- **Calibratable = numeric-constant auxes/flows only.** Stocks are rejected; **fitting stock initial conditions is unsupported in 0.10.0** (PySD `params=` pins, not initializes). Non-constant equations are rejected (fitting them would change model structure).
- **One shared observation time grid** across all targets (per-target grids reserved).
- **No plotting.** Structured data + an optional best-fit `fit_series` and optional CSV, consistent with `simulate`/`analysis`.
- **`time_window` override, per-target grids, and a DE→least_squares uncertainty-polish pass are reserved**, not shipped.

**Why first:** the loader, the time-alignment, and the residual builder are testable as pure-ish functions *without* running an optimizer. Getting them right (and fail-fast) is the foundation; the optimizer loop in Task 2 just calls them.

- [ ] **Step 1 — Declare scipy in the `sim` extra.** `pyproject.toml`: add `scipy>=1.10` to the `sim` optional-dependency list (alongside `pysd>=3.14`). `uv lock`. Confirm no new package is *added* to the resolution (already present via pysd) — only the direct edge is recorded.
- [ ] **Step 2 — Extract `constant_parameter_value(model, key) -> float | None`** into `simulate.py`: returns the defining numeric constant for a **constant aux/flow**, and **`None`** for a stock or any equation that does not parse to a single float. This is the shared eligibility/`initial`-default primitive (generalizes `analysis.py`'s private `_baseline_param_value`; point that helper at it if trivial, else leave analysis untouched). Keep all sim-stack imports (`numpy`, `scipy`, `pandas`, `pysd`) **inside functions** in `calibrate.py` — never at module top — so the server imports without the `sim` extra (review: lazy imports include numpy).
- [ ] **Step 3 — Observation loader `_load_observations(spec, model)`.** Accept **either** inline `{"time": [...], "targets": {var: [...]}}` **or** `{"csv_path": "..."}` (first/`time` column = time; remaining named columns → model variables; pandas import local to this helper). Validate atomically *before any run*: every target name resolves to a model variable (reuse `run_simulation`'s name resolution; error names the bad variable + valid list); each series length == time length; **time strictly increasing** (rejects duplicates); all values finite (`_require_finite`). Return a normalized `{times: ndarray, targets: {name: ndarray}}`. One shared `times` grid for all targets (documented limitation).

Linear-interpolate each simulated target onto `obs_times` (`numpy.interp`). **Warn** when `min(diff(obs_times)) < dt` (obs denser than the save grid → interpolation under-resolves the dynamics). Emit the model's time units in the result. Document the interpolation + clamp caveat in the module docstring.
- [ ] **Step 5 — Residual/objective builder `_residuals(x, display_keys, runner, obs, weights)`.** Build `params = {display_keys[i]: x[i]}` (**display-name keyed** — the names were resolved once upstream, not zipped raw). One `runner.run(params=params)`; align; stack `w_t·(sim_interp − obs)` across targets into a 1-D vector. A **non-finite** simulation for a trial returns a **distance-aware** penalty residual (`base·(1 + ‖x − x_last_feasible‖)`, scaled) + records a capped warning — never NaN to the optimizer, never a flat plateau. Provide `_sse(residuals)` for the DE scalar path.
- [ ] **Step 6 — Failing tests for the primitives:**

  - Obs denser than `dt` emits the under-resolution warning.
  - `_align` reproduces sim values exactly when obs times equal the sim save grid; interpolates correctly at a midpoint.
  - A trial producing NaN yields a finite, distance-growing penalty residual + a warning, not an exception.

### Task 2: `calibrate` core (both optimizers)

**Files:** Extend `stella_mcp/calibrate.py`, `tests/test_calibrate.py`.

**What it answers:** "what parameter values best reproduce this observed data, and how well-determined are they?"

**Signature (Python):**
```python
def calibrate(model, observations, parameters, *, method="least_squares",
              objective="sse", weights=None, max_nfev=1000,
              maxiter=None, popsize=15, seed=SEED,
              return_fit_series=False, save_fit_csv=None): ...
```

- [ ] **Step 1 — Parameter setup + eligibility gate (BLOCKER fix).** Resolve each parameter `name` to its model variable and its PySD **display name** (precompute the `{name: display}` map once). Classify each via `constant_parameter_value`: if it returns `None`, **raise** naming the parameter — "stocks pin to a constant under PySD `params=`, suppressing integration; fitting stock initials is unsupported in 0.10.0" / "non-constant equation — fitting would change model structure." Only constant auxes/flows proceed. Build `x0` (each `initial` or `constant_parameter_value`), `lower`/`upper`. Validate `min < max`, `initial ∈ [min, max]`. `differential_evolution` → **raise** if any bound is missing/non-finite. `least_squares` → `trf` (bounded or unbounded). **Require finite residuals at `x0`** — if the initial point is infeasible, raise rather than let the penalty fake a converged fit.
- [ ] **Step 2 — Optimize over the shared runner.** Open `_compile_runner(model)` **once**; inside the `with`:
  - `least_squares(_residuals, x0, bounds=(lower, upper), max_nfev=max_nfev, ...)` (residual-vector path), or
  - `differential_evolution(lambda x: _sse(_residuals(x, ...)), bounds=list(zip(lower, upper)), maxiter=maxiter_eff, popsize=popsize, ...)` where `maxiter_eff` is `maxiter` if given, otherwise the fixed default `100` — **do not** pass `max_nfev` as `maxiter` (review). Seed via `rng=seed` where the installed scipy supports it, else `seed=seed` (deprecation-safe). Report `result.nfev`.
- [ ] **Step 3 — Uncertainty (least_squares only).** `SSE = 2·result.cost` (= `Σ result.fun²`). Compute `std_error = sqrt(diag(SSE/(m−n)·inv(JᵀJ)))` **only when** `m > n`, `JᵀJ` is full-rank/well-conditioned, and **no fitted parameter is at a bound** (feed the `at_bound` flags in — an active bound removes a DOF). Otherwise `std_error = None` + a warning naming the reason (`dof≤0` / rank-deficient / ill-conditioned / active bound). Optionally report `cond(JᵀJ)`. Under non-default `weights`, attach the inverse-σ caveat. DE → `std_error = None`.
- [ ] **Step 4 — Assemble result.** `converged = result.status > 0` for `least_squares` (status `0` = `max_nfev` reached → `converged: false`; flag "terminated at initial guess" when `nfev` is tiny and `x ≈ x0`); DE → `result.success`. Prepend `method_warnings(model)` (Euler-backend note) to `warnings`. Emit M1 warning when targets span >1 order of magnitude and `weights is None`. Per-parameter `{name, initial, fitted, std_error, bounds, at_bound}`; plus `objective {metric, initial, final, rmse}`, `n_observations`, `n_function_evals`, `targets`, `time_units`, `warnings`, and — when `return_fit_series` — the best-fit downsampled series via `summarize_run`. Optional `save_fit_csv` (long table: time, target, observed, fitted), mirroring `simulate`'s CSV.
- [ ] **Step 5 — Recover-the-truth + edge tests:**
  - **Synthetic-truth recovery:** simulate a known model at a known constant value to generate "observed" data; perturb the guess; assert recovery within tolerance — for **both** optimizers.
  - **Stock rejection:** a stock listed as a parameter raises with the explanatory message (BLOCKER regression).
  - **False-convergence guard:** an `x0` in an infeasible (non-finite) region raises rather than returning `converged: true` with `x == x0`.
  - Multi-target fit with per-target `weights` recovers a 2-parameter truth; multi-scale targets without weights emit the M1 warning.
  - A parameter driven to a bound reports `at_bound: true`, `std_error: None` + warning.
  - `least_squares` reports a finite `std_error` (well-posed case); DE reports `None`.
  - DE honors a small `maxiter` and reports `nfev` consistent with `maxiter·popsize`; `max_nfev` exhaustion on `least_squares` → `converged: false` without raising.
  - Missing bound for `differential_evolution` raises; `min ≥ max` and `initial` out of bounds raise.
- [ ] **Step 6 — Verify, commit.**
```bash
uv run --extra dev --extra sim python -m pytest tests/test_calibrate.py -v
git commit -m "feat: add calibrate parameter-fitting tool"
```

- **Spec coverage:** the third and final tool of the simulation arc; Bayesian calibration explicitly deferred.
- **Review-hardened:** two independent reviews folded in (2026-06-14). The one blocker (stocks pin to constants under PySD `params=`) is resolved by the constant-only eligibility gate; the two HIGHs (display-name contract, flat-penalty false convergence) and the MEDIUM/LOW hardening are mapped onto specific steps above.
- **Dependency discipline:** zero new installs — `scipy`/`pandas`/`numpy` already arrive via `pysd`. We declare `scipy` directly because we import it directly. **All** sim-stack imports are inside `calibrate.py` functions so the server imports without the `sim` extra (regression-checked in Task 4).
- **Engine reuse:** built on `_compile_runner`; the optimizer calls `.run(params=)` repeatedly on one compiled model — the access pattern the 0.9.0 PySD-statelessness verification already cleared. Trial params are keyed by resolved **display names**, matching `run_simulation`'s name contract.
- **Method honesty (coding cardinal #3):** the four forks are named, defaulted explicitly, and forward-compatible (enums, not silent defaults). `std_error` is labeled an approximation with its validity conditions (dof, conditioning, active bounds, inverse-σ weights), not a posterior. No extrapolation; no silent `final_time` change; stocks are rejected rather than silently flattened.
- **Failure discipline:** target/parameter typos, stock/non-constant parameters, and bad bounds fail fast and atomically; an infeasible `x0` raises; per-trial non-finite simulations become **distance-aware** penalty residuals + capped warnings (no flat plateau, no false convergence); `converged` is gated on the optimizer's real status; out-of-window obs are rejected by an explicit pre-check, not extrapolated by `interp` clamping.
- **No-crash math:** `std_error = None` + warning on `dof≤0` / rank-deficient / ill-conditioned / active-bound; DE → `None`; no divide-by-zero in covariance or RMSE.
- **Reproducibility:** DE seeded with a named non-null `SEED` (via `rng`/`seed` deprecation-safe); `least_squares` deterministic. Tools never mutate the session model (run on copies via the shared runner); the only side effect is the opt-in CSV.
- **Tests:** the synthetic recover-the-truth pattern for both optimizers, plus explicit regressions for the review findings (stock rejection, false-convergence guard, boundary alignment, at-bound covariance, DE budget, multi-scale weight warning).
